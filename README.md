# valorant
# 🎮 Tactical Strike

Мой собственный 3D-шутер,
созданный на HTML и JavaScript.

## Возможности
- 3D-карта
- Противники с искусственным интеллектом
- Три вида оружия
- Система здоровья
- Способности и гранаты

## Управление
- WASD — движение
- ЛКМ — стрельба
- R — перезарядка
- Shift — тихий шаг

## Технологии
- HTML
- CSS
- JavaScript
- Three.js
- GLB 3D Models
